# Community code of conduct

We welcome people with different backgrounds and levels of trading or software experience. Be respectful, assume good intent, and critique ideas and code rather than people.

Harassment, discrimination, threats, unwanted sexual attention, doxxing, publishing private account data and persistent disruption are unacceptable. Do not pressure contributors to share financial records or credentials.

Maintainers may edit or remove harmful content, close disruptive discussions and restrict participation. Enforcement should be proportionate and respect privacy. For a private conduct concern, contact the maintainer through an available private channel on [their GitHub profile](https://github.com/kirasvg); if none is available, request a private contact channel without posting incident details. Vulnerability reports belong in the channel described in SECURITY.md.

This policy applies to project issues, pull requests, discussions and other project-managed spaces. It does not require endorsement of a trading strategy, financial outcome or commercial service.
